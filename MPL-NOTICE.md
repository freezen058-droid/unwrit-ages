MPL-2.0 is a *per-file* copyleft, so this notice splits the tree in two:

* **Covered Files we modified.** §3.2 obliges us to make their Source Code Form

* **Files we added.** §3.3 lets these be distributed as part of a Larger Work under

Files that came from upstream and are *unchanged* here need no offer from us; get them
from upstream Unciv at the commit named below.

## How the source is offered

The modified Covered Files are offered on request, by email, free of charge, to anyone who
has a build (user, 2026-09-24: no public download). <https://unwritages.pages.dev/license.html>
says so and gives the address; the app links that page under **Options → About**
(`Constants.licenceUrl`, `core/src/com/unciv/Constants.kt`). That line is what satisfies
§3.2(a) - telling recipients how to obtain the source - so it must stay in every build.

Make the archive with `tools/mpl_source_bundle.py` and send it to whoever asks; the 1.0.0
archive is kept at `store/mpl-source-1.0.0.tar.gz` (not in git, not on the website).

The archive holds every modified Covered File at its path in this fork, plus `LICENSE`,
a `MANIFEST` listing all of them with sha256 and byte size, and a `DELETIONS` list of
the Covered Files this fork removed. It is not a buildable game: it has no gradle
wrapper, no unmodified upstream files, and none of the files listed under §3.3 below.

## Regenerating the archive and this notice

```
python tools/mpl_source_bundle.py --update-notice     # refresh the block above from git
python tools/mpl_source_bundle.py --stage-website     # build, verify, copy into website/
npx wrangler pages deploy website --project-name unwritages --branch main
```

The script takes its file list from git, then verifies the finished archive against
git: the member list must equal the `--diff-filter=M` set, none of the
`--diff-filter=A` files may appear, and known-modified files must be present. It exits
non-zero if any of that fails, and `--check-notice` exits non-zero if the counts above
have drifted from git. Run both for every release and re-upload the result.

## Corrections to the 2026-09-17 revision of this notice

That revision listed 30 paths generated by `git diff --name-only`, which does not
distinguish modified files from added ones. It was wrong in both directions: it
published six *added* wallet files as if MPL required it, listed one file this fork had
*deleted*, and omitted 23 Covered Files that really were modified — including
`GameInfo.kt` and `TileInfoTable.kt`. Hence the `--diff-filter`, the generated block,
and `--check-notice`: this notice no longer carries a hand-kept list or a hand-typed
count.
