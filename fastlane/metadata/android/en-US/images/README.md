# Store images

`icon.png` (512x512) and `featureGraphic.png` (1024x500) are generated from the game's own
tiles by `pic/batch_review/_sd/storeart.py`, so they are ours and they match what the game
actually looks like.

`phoneScreenshots/` must be captured from the running game - a store listing needs at least
two, 16:9 or taller, no device frame, no added text. Suggested: the world map early on, a
city screen, the tech tree, and a late-game map showing the terrain set.
